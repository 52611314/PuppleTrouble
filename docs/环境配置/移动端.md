# 移动端环境配置

主责 D。返回[环境配置入口](../环境配置说明.md)，启动见[项目启动](../项目启动.md)。本页命令从仓库根目录开始，修改前先阅读[HANDOFF](../HANDOFF.md)。

## Android 工具

安装稳定 Android Studio、Android SDK／模拟器，准备一台实体 Android 手机。初始计划 minSdk 26、compileSdk/targetSdk 36；JDK 17 为候选，D 在周期 1 核对选定 AGP 的兼容要求，实际构建后固定 Kotlin、AGP、Gradle Wrapper 和 Compose BOM。

当前没有 android 工程、Wrapper 或安装包。工程建立后提交构建脚本、Wrapper、libs.versions.toml 和必要配置，不提交本机 SDK 路径、签名文件或生成产物。

## API 地址

Android Studio 打开未来 android 目录。本机 local.properties 保存 SDK 路径并增加 API_BASE_URL，由 Gradle 显式读入构建配置；该读取逻辑也需要 D 实现。

模拟器配置：

```properties
API_BASE_URL=http://10.0.2.2:8000/api/v1/
```

模拟器通过 10.0.2.2 访问电脑；模拟器的 127.0.0.1 是它自己。USB 真机可以执行：

```powershell
adb devices
adb reverse tcp:8000 tcp:8000
```

然后真机配置改为 `API_BASE_URL=http://127.0.0.1:8000/api/v1/` 并重建，使配置生效。reverse 仅连线调试可用；局域网方案需明确配置电脑地址、监听和防火墙，默认不扩大服务暴露。

HTTP 只由 debug 网络策略放行，release 使用 HTTPS。模型 key、数据库密码和 JWT_SECRET 不能进入 App；访问令牌首版仅在内存保存，重启后重新登录。

## 工程建立后的构建

Android Studio 同步并选择设备 Run；或从根目录执行：

```powershell
Set-Location android
.\gradlew.bat assembleDebug
```

当前无工程，命令不可运行；APK 路径以实际构建输出为准。原生预览使用共享模板 schema，不依赖 Web 编辑器进程；相同角色保持相同规范色值。
