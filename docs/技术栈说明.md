# PuppleTrouble 技术栈说明

2026-11-10 工程基线。三个工程已建立，业务模块尚待开发；启动与实际验证见[项目启动](项目启动.md)，环境由团队自行配置。

## Web

| 环节 | 已接入的依赖／配置 | 当前使用范围 |
|---|---|---|
| React／TypeScript／Vite | React 19.3.1、TypeScript 5.9.3、Vite 7.3.8 | 首页、类型检查、开发与生产构建 |
| 样式 | Tailwind CSS 4 与 Vite 插件、原生 CSS | 启动首页与响应式样式 |
| 路由／状态 | React Router、TanStack Query 5.107.1 | Router 已包裹应用，Query 管真实健康请求；产品路由待实现 |
| API | fetch、Zod 4 | 超时、响应结构校验；业务令牌逻辑待实现 |
| 画布／草稿 | Konva、react-konva 19.3.2、Zustand | 依赖已安装，业务画布、锁定和撤销仍预留 |
| 检查 | Vitest、Testing Library、Playwright | 断连提示与真实后端浏览器连接验证 |

Node 最低 22.12，本次使用 24.13.0；npm 与 package-lock.json 管理依赖，首次和依赖变化后用 npm ci。确切全量版本以锁文件为准。[Vite 官方环境要求](https://vite.dev/guide/)。

## 后端与数据库

| 环节 | 技术／工具 | 当前使用范围 |
|---|---|---|
| 语言与服务 | Python 3.12、FastAPI、Uvicorn | 应用工厂、HTTP 服务、存活与数据库就绪检查 |
| 数据校验／配置 | Pydantic、pydantic-settings | 配置读取、输入输出结构、秘密字段与启动校验 |
| 公共接口框架 | FastAPI 中间件、统一响应与异常处理 | 请求标识、CORS、错误去敏；业务接口待实现 |
| 数据访问 | SQLAlchemy 2、psycopg 3 | PostgreSQL 连接、会话及 users ORM 模型 |
| 数据库／迁移 | PostgreSQL 16、Docker Compose、Alembic | 独立开发数据库、命名卷、初始 users 迁移；其余业务表待实现 |
| 认证依赖 | PyJWT、pwdlib／Argon2 | 已安装，登录、令牌及权限逻辑待实现 |
| 文件／外部请求 | python-multipart、httpx | 已安装，上传和真实模型调用待实现 |
| 验证 | pytest、FastAPI TestClient | 公共接口、跨域、数据库错误去敏及配置路径验证 |

backend/requirements.txt 为直接依赖范围；requirements.lock.txt 为本次 Windows／Python 3.12 的全量固定依赖，包含测试与图像库。不同系统需另外验证。ORM 不自动 create_all，数据库结构只经 Alembic 迁移。

## 算法与 AI

| 环节 | 技术／工具 | 当前状态与计划用途 |
|---|---|---|
| 图像读取／归一化 | Pillow | 已安装并验证导入；方向、ICC、sRGB、透明背景处理待实现 |
| 图像计算／蒙版 | OpenCV（headless）、NumPy | 已安装并验证导入；采样、区域与蒙版计算待实现 |
| 色彩科学 | colour-science | 已安装并验证导入；颜色空间转换、感知色差等校验待实现 |
| 聚类／候选色 | scikit-learn | 已安装并验证导入；代表色提取与聚类策略待实现 |
| 意图与解释 | 计划接入千问多模态 API，复用服务端 HTTP 客户端 | 适配器、意图解析与解释尚未实现；当前无需模型 key 即可启动工程 |
| 输出约束 | Pydantic schema 与自有规则模块 | 算法文件当前为空；计划检查色值、锁定、来源及版本，再生成可确认候选 |

算法与 AI 复用后端 Python 环境，不额外部署独立服务。安装依赖不代表已完成取色或模型接入。

模型不猜色号、不直接写用户版本。候选必须通过约束校验、显示来源、由用户确认；mock 与规则备用必须明示。详见[架构设计](架构设计.md)。

## Android

| 项 | 固定值／当前实现 |
|---|---|
| 构建 | Gradle Wrapper 8.14、AGP 8.13.1、Kotlin 2.2.20 |
| JDK／字节码 | 构建使用 JDK 21，Java／Kotlin 目标 17 |
| SDK | minSdk 26、compileSdk/targetSdk 36；Build Tools 35.0.0 |
| UI | Compose UI 1.8.3、Material 3 1.3.2、Activity Compose 1.10.1 |
| 编译插件 | Compose Compiler 插件版本与 Kotlin 同为 2.2.20 |
| 网络 | 当前使用系统 HTTP 客户端＋Coroutines 检查健康，超时／失败可重试 |
| 后续业务 | ViewModel／StateFlow、Retrofit／OkHttp、Room、Coil、DataStore、原生 Canvas 等在对应功能阶段接入 |

版本目录为 android/gradle/libs.versions.toml；本工程显式固定 Compose 库版本，不使用尚未配置的 BOM。HTTP 只在 debug 开启，release 需指定 HTTPS API；当前未配置发布签名，验证包为 debug APK。[AGP 官方兼容要求](https://developer.android.com/build/releases/agp-8-13-0-release-notes)、[Compose 编译插件](https://developer.android.com/develop/ui/compose/setup-compose-dependencies-and-compiler)。

## 责任与工具

A 主责 Web，兼架构与后端公共框架；B 主责业务／数据库；C 主责算法／AI；D 主责移动并每六天组织联合测试。配置环境由团队自行处理，不按变量分配个人。工具包括 Git、Docker Desktop、Android Studio、编辑器、pytest、npm 和 Gradle Wrapper。

用户产品场景与真实模型评测不属于本次启动验证，不因库已安装而宣称完成。参赛演示和技术材料必须反映真实实现。
