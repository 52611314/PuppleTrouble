# 算法与 AI 环境配置

主责 C，B 配合业务接入。返回[环境配置入口](../环境配置说明.md)。命令从仓库根目录执行，修改前先阅读[HANDOFF](../HANDOFF.md)。

## 共用后端环境

按[后端环境](后端.md)建立 Python 3.12 venv，并从 backend/requirements.txt 安装候选依赖。Pillow、OpenCV、NumPy、colour-science、scikit-learn 与 FastAPI 共用该环境，不另起数据库或公开 API。

如临时使用 Jupyter 做探索，不让 Notebook 隐藏状态成为生产依赖；正式处理和复现入口交付为可独立执行的模块及样例。库版本解析后与 B 统一锁定。

## 模型配置与模拟模式

根目录 `.env` 中的 MODEL_API_KEY、MODEL_API_BASE_URL、MODEL_NAME 仅在服务端使用。真实接入时按供应商实际配置填写，并将 AI_MODE 改为 real。当前没有模型适配实现，填写参数不会自动产生可调用业务。

AI_MODE=mock 只用于明确标识的开发模拟，结果和 UI 都要显示来源；生产不得启用。真实 AI 超时或格式错误时保留旧项目，可提供标为规则方案的备用结果，不能把规则输出称作真实模型完成。

## 图像、资料和复现约定

- 输入记录图像来源与许可，进行方向／ICC／sRGB／透明背景处理，限制解码像素及文件体积。
- 模型负责语义、意图和解释；色号、蒙版、覆盖率由确定性计算产生，不让模型猜测。
- 每组样例包含输入版本、处理参数、算法／提示版本、预期约束、实际结果及误例；私人上传不提交。
- 公开作品预计算统计，缓存键包含图像和算法版本；交互阈值与局部采样使用固定样例核对。
- 规范色值与图像坐标交给 A/D，模型失败、取消和候选提交行为与 B 的业务服务统一。
