# 算法与 AI 环境配置

所有成员自行配置本机环境。返回[配置入口](../环境配置说明.md)，共用[后端 Python 环境](后端.md)。

## 图像依赖

安装 backend/requirements.lock.txt 包含 Pillow、OpenCV、NumPy、colour-science、scikit-learn。库已随后端依赖解析，业务算法文件当前为空；安装库不代表已经实现取色、蒙版、配色迁移或评测。不另建公开 API、数据库或独立 Python 环境。

图像处理将按方向／ICC／sRGB／透明背景统一，再进行确定性取色与蒙版计算。输入记录许可与来源，私人上传不提交；样例记录参数、图像版本、算法版本、输出和误例。

## 模型配置

MODEL_API_KEY、MODEL_API_BASE_URL、MODEL_NAME 只在根目录 .env 的服务端使用。当前无需 key 即可启动框架；后续接真实模型再填入自己的配置，并改 AI_MODE=real。密钥不得进入 VITE_ 变量或 Android 安装包。

AI 适配、意图与解释文件已预留为空，当前没有真实或模拟调整接口。未来 mock 必须在结果和 UI 明示，规则备用也不得伪装成模型结果。模型输出需经过 schema、色值、锁定、来源和版本校验，用户确认后才能保存。

计划 D12 前提供真实模型局部调整记录，D21 前固定样例与复现入口；尚未建立的算法命令不列为可运行命令。Jupyter 仅探索，正式交付可独立执行模块，不能依赖 Notebook 隐藏状态。
