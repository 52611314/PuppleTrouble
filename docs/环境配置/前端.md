# 前端环境配置

主责 A。返回[环境配置入口](../环境配置说明.md)，完整启动见[项目启动](../项目启动.md)。本页命令从仓库根目录开始；修改前先阅读[HANDOFF](../HANDOFF.md)。

## 工具与当前状态

Node.js 22（至少 22.12）及 npm。技术采用 React、TypeScript、Vite、Tailwind CSS、Konva 等，详见[技术栈](../技术栈说明.md)。当前 frontend 仅有 `.env.example`，没有 package.json，因此安装／启动／测试脚本暂不可运行。

A 在周期 1 初始化工程后，提交 package.json、package-lock.json、类型与构建配置；实际构建确认 React/react-konva 兼容性，再记录版本。

## 本机公开配置

首次复制，已有文件不覆盖：

```powershell
Copy-Item -LiteralPath frontend/.env.example -Destination frontend/.env.local
```

开发配置为 `VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1`。Vite 变量会进入浏览器，只允许公开配置；模型 key、JWT_SECRET、数据库密码不得放入 VITE_ 变量。

## 工程建立后的命令

以约定脚本已提交为前提：

```powershell
Set-Location frontend
npm ci
npm run dev
```

依赖变化后重新 npm ci。使用终端实际地址，默认 localhost:5173；后端 CORS_ORIGINS 应允许实际使用的 localhost／127.0.0.1:5173。端口被自动更换时同步配置或恢复 5173。

检查脚本约定为 `npm run build`、`npm run test`、`npm run test:e2e`；它们需要实际工程及测试环境，当前未执行。Playwright 浏览器环境由 A 在工程建立后写明安装命令。

## 部署与常见问题

- 构建生成 dist；生产使用静态服务器及同域 API 反向代理，打包时设置 `VITE_API_BASE_URL=/api/v1`。Vite 开发服务不用于发布。
- 认证图片通过带权限的 fetch 获取 Blob 等受控方式加载，不把私人图片公开以绕过跨域。
- PNG 导出须等字体和图片加载完成，并处理跨域资源，避免画布无法导出。
- 遇到版本冲突保留草稿；颜色显示差异先核对 sRGB、源色值与渲染，不能以压缩截图证明原始色号。
