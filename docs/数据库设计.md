# PuppleTrouble 数据库设计

记录实体、约束、模块归属与迁移状态。采用 PostgreSQL 16，ID 为 UUID，时间为带时区时间，API 用 UTC ISO 8601。这里只参考外部文档的组织方式，沿用本项目的颜色与版本契约。

## 当前迁移状态

数据库相关内容按用途分布，当前没有单独的 database 文件夹：

| 位置 | 用途 |
|---|---|
| `compose.dev.yaml` | PostgreSQL 16 服务、端口映射及持久卷声明 |
| 根目录 `.env`（本机、不提交） | 数据库名、连接用户、密码及后端 DATABASE_URL |
| `backend/app/core/database.py` | SQLAlchemy 连接、会话和 ORM 基类 |
| `backend/app/modules/auth/models.py` | 已实现的 users 表模型；后续模型放到对应业务模块 |
| `backend/alembic/`、`backend/alembic.ini` | 可提交、可复现的数据库结构迁移 |
| Docker 命名卷 `puppletrouble-dev_postgres_data` | 默认 Compose 项目名下的实际数据，挂载到容器 `/var/lib/postgresql/data`；不在仓库内 |
| `scripts/backup-db.ps1`、`scripts/restore-db.ps1` | 按开发计划预留，当前为空，尚不能备份或恢复 |

共享的是模型与迁移，各电脑独立生成本机数据。克隆仓库后需启动 PostgreSQL 并执行迁移；不会自动获得另一台电脑的账号或数据。卷名可能随 Compose 项目名变化，以实际挂载为准。连接、账号和端口方案见[环境配置说明](环境配置说明.md#数据库连接与端口调整方案)。

- 初始迁移：`backend/alembic/versions/0001_initial_users.py`，revision=`0001_initial_users`，down_revision=None。
- 当前实现表：`users`；Alembic 自身维护 `alembic_version`。
- 初始迁移只建账号结构，不写入演示账号、密码、作品或用户项目。认证 API 尚未实现。
- 下文其他表是目标设计，相关 models.py 已预建为空，尚无对应业务迁移；空文件不构成模型实现。
- 当前连接与迁移命令见[项目启动](项目启动.md)，实际验证记录见该页末尾。

## 账号结构：已实现

| 字段 | 类型／约束 | 用途 |
|---|---|---|
| id | UUID，主键，应用生成 | 用户标识 |
| email | varchar(254)，非空、唯一 | 登录邮箱；后续 Service 统一标准化再写入 |
| password_hash | varchar(255)，非空 | 仅存密码哈希，禁止存明文 |
| created_at／updated_at | timestamptz，非空 | 创建／更新时间；ORM 更新时维护 updated_at |

唯一约束由数据库兜底；认证、密码强度、限流和资源授权在 Service 层逐步实现，不因表存在而视为已完成。

## 颜色、作品与素材：待实现

| 表 | 关键字段 | 约束／索引 |
|---|---|---|
| colors | id、hex、display_name、family、tags、hue、lightness、editorial_rank | hex 大写 #RRGGBB，索引 family／hue／id；中性色独立排序 |
| artworks | id、title、creator、date_text、source_url、license、image_asset_id、image_version、review_status | 审核通过后可发布；图像与版本绑定；来源不由模型伪造 |
| artwork_colors | artwork_id、color_id、coverage、sample_hex、algorithm_version | 复合唯一；coverage 在 0～1；不称作语义物体面积 |
| assets | id、owner_user_id、visibility、storage_key、media_type、width、height、image_version、normalization | owner 对私人素材非空；索引 owner／created_at；宽高为正，访问经服务鉴权 |
| templates | id、name、scene、canvas_schema_version、document_json、review_status | 模板 schema 校验后存 JSONB；禁止脚本及任意 HTML |
| knowledge_entries | id、source_type、source_url、license、statement、review_status | 说明与作品事实分开，可追溯引用 |

assets 的 visibility 限 public/private；公共作品素材也保留来源。蒙版作为 asset，与原图 image_version 关联。原始大图不塞进 JSONB 或 Git，磁盘文件名不直接使用用户输入；元数据与真实文件删除由 Service 协调。

## 项目与版本：待实现

| 表 | 关键字段 | 约束／索引 |
|---|---|---|
| projects | id、owner_user_id、title、template_id、current_version、created_at、updated_at | 索引 owner／updated_at／id，current_version>=1 |
| project_versions | id、project_id、version、palette_id、document_json、created_at | 唯一(project_id,version)，palette_id 全局唯一，文档快照不可原地覆盖 |
| project_assets | project_id、asset_id | 复合主键，提供私有素材引用约束 |
| proposals | id、owner_user_id、project_id、base_version、palette_roles、changes、analysis_source、evidence_refs、expires_at | 来源 model/rule/mock；索引 project／base_version；候选只读、过期不得保存 |

保存版本用单个事务校验 owner 和 base_version，原子更新 current_version，再插入不可变快照。并发失配返回 409，不能最后写入覆盖。恢复历史是新增快照和版本号，不能改回旧版本号。palette_id 对应已保存版本的方案，是收藏 palette 的合法目标。

document_json 校验角色颜色、locked_roles 与角色 locked 一致；保留元素内容、布局、图像与图表数据。候选锁定列表与已保存状态取并集，不能通过省略字段绕过锁色。

## 任务、收藏与偏好：待实现

| 表 | 关键字段 | 约束／索引 |
|---|---|---|
| jobs | id、owner_user_id、project_id（可空）、kind、status、base_version、result_json、error_code、created_at、expires_at | status 限 queued/running/succeeded/failed/cancelled；索引 owner／status／created_at |
| idempotency_keys | owner_user_id、method、path、key、request_hash、status_code、response_json、expires_at | 唯一(owner,method,path,key)，24 小时有效；同 key 不同正文返回 409 |
| favorites | id、owner_user_id、kind、color_id／artwork_id／palette_id | 三个目标恰好一个非空，分别外键；每种目标按用户唯一；API 仍使用 kind/id |
| preferences | id、owner_user_id、scope、project_id、statement、evidence_version、confirmed | personal/project 范围与 project_id 一致；个人偏好显式确认；删除清相关缓存 |
| exports | id、owner_user_id、project_id、version、format、asset_id／storage_key、expires_at | 绑定已保存版本与下载权限，服务端首版支持 JSON，PNG 按客户端能力导出 |

任务结果不保存秘密、完整提示中的私人信息或隐藏推理。个人收藏 palette 时校验版本所有权，不能仅因 UUID 存在而授权。重复提交的保留结果不能泄露给另一用户。

## 建模和删除规则

- 通用时间使用 timestamptz，业务状态使用字符串加 CheckConstraint；比例用限定范围的 Numeric，色值用长度／格式约束。
- JSONB 用于页面、结果和来源引用，进入数据库前先经 Pydantic／算法校验；数据库不承担 AI 推理。
- 用户的私人项目、任务、偏好、收藏按服务策略删除；共享公开作品不随用户级联删除。
- 删除项目先取消活动任务并移除引用，再按策略清理未被引用的私人素材；被引用素材直接删除返回 409。
- 迁移只改结构，资料导入另行提供审核命令；新增迁移前核对生成 SQL，不能把未完成的空 revision 放入版本目录。
- 备份先覆盖结构与用户数据，恢复必须在独立环境验证；计划中的脚本目前为空，不列为可运行命令。

ORM／Service／Repository 的目录见[架构设计](架构设计.md)，接口行为见[接口文档](接口文档.md)。
