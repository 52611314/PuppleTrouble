# PuppleTrouble 功能对应的模块

本页按功能列出 Web、后端、Android 和接口入口，区分已实现、仅预留与后续计划。所有相对路径均以仓库根目录为准；未写完整前缀的接口默认位于 /api/v1；未实现模块不注册假成功接口。


## 1. 启动与连接检查


### Web

```text
frontend/src/App.tsx
frontend/src/shared/api/client.ts
```


### 后端

```text
backend/app/api/v1/endpoints/health.py
backend/app/core/database.py
```


### Android

```text
android/app/src/main/java/com/puppletrouble/app/MainActivity.kt
android/app/src/main/java/com/puppletrouble/app/data/HealthRepository.kt
```


### 接口与调用链

GET /api/v1/health；GET /api/v1/health/ready。除启动检查外，业务遵循客户端→API→Service→Repository／算法；AI 候选在服务端校验，用户确认后才保存。

### 当前真实状态

已有运行检查实现，Web／Android 请求真实后端；首页色卡是明确标识的本地示例，不是作品分析结果。
