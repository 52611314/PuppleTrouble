# 前端环境配置

所有成员自行配置本机环境。返回[配置入口](../环境配置说明.md)，逐步命令见[项目启动](../项目启动.md)。

## 工具与依赖

安装 Node.js 22.12 以上，本次使用 Node 24.13。工程为 React 19、TypeScript 5.9、Vite 7，已有 package.json、package-lock.json、Tailwind 插件、API 客户端和首页。首次在 frontend 执行 npm ci，后续仅依赖变化时重装。

## 公开配置

在根目录运行 scripts/setup-local.ps1 生成 frontend/.env.local，或首次从 frontend/.env.example 复制。默认 `VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1`。Vite 变量进入浏览器，不能放模型 key、JWT_SECRET 或数据库密码。

## 运行和检查

从根目录进入 frontend：

```powershell
Set-Location frontend
npm ci
npm run dev
```

浏览 http://127.0.0.1:5173 ，连接已运行后端时显示连接正常。5173 被占用会报错，不自动换端口。修改 Vite 环境变量后重启。`npm run build` 做类型检查并输出 dist；`npm run preview` 在 4173 预览构建。

`npm run test` 验证断连时的恢复提示；`npm run test:e2e` 要求后端运行，使用本机 Microsoft Edge 检查真实连接。当前只有启动页面，产品功能文件已预留但为空。

## 跨域与发布

后端 CORS_ORIGINS 允许 localhost／127.0.0.1:5173 及本地构建预览的 4173。生产构建建议 VITE_API_BASE_URL=/api/v1，并由静态服务器代理同域 API。Vite dev server 不用于生产。

后续认证图片使用带权限请求获取 Blob 等受控方式，不将私人图片公开来绕过跨域；导出前等待字体／图像加载。当前 PNG 导出尚未实现。
