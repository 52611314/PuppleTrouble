## 项目目录与本机配置

根目录为包含 README.md、backend、frontend、android、compose.dev.yaml 的 PuppleTrouble 目录，不要求组员采用同一绝对路径。所有相对命令从根目录开始，遇到 Set-Location 后以切换后路径为准。

运行 `scripts/setup-local.ps1` 可生成不覆盖已有文件的本机配置。根目录 .env 具有随机开发密码；不复用参考项目的密码、数据库或端口。

| 位置／变量 | 用途 |
|---|---|
| 根目录 .env：APP_ENV、DATABASE_URL | 运行环境及真实数据库连接；主机地址 127.0.0.1:5432 |
| POSTGRES_DB／USER／PASSWORD | 本项目开发数据库 puppletrouble；密码只保存在本机 |
| JWT_SECRET、STORAGE_DIR | 服务端签名秘密及私有存储位置；业务认证／上传尚未实现 |
| MAX_UPLOAD_MB／MAX_IMAGE_PIXELS | 后续图像输入限制，当前只是配置预留 |
| MODEL_API_KEY／MODEL_API_BASE_URL／MODEL_NAME、AI_MODE | 未来真实模型接入；密钥只在服务端，当前无调整接口 |
| CORS_ORIGINS、ALLOW_DEV_HTTP | 明确允许开发来源；生产禁用开发 HTTP 与模拟配置 |
| frontend/.env.local：VITE_API_BASE_URL | 浏览器可见的 API 地址，不含秘密 |
| android/local.properties：sdk.dir／API_BASE_URL | 本机 SDK 与构建期 API 地址，禁止提交 |

后端总是从根目录 .env 显式加载；Compose 的 --env-file 不等于主机 Python 自动获得变量。STORAGE_DIR 相对路径按根目录解析。

## 本地端口与启动顺序

| 组件 | 地址 |
|---|---|
| 数据库 | 127.0.0.1:5432，仅开发本机 |
| 后端／API 文档 | http://127.0.0.1:8000/api/v1 ／ http://127.0.0.1:8000/docs |
| Web 开发／构建预览 | http://127.0.0.1:5173 ／ http://127.0.0.1:4173 |
| 模拟器访问后端 | http://10.0.2.2:8000/api/v1/ |
| USB reverse 后真机 | http://127.0.0.1:8000/api/v1/ |

顺序为 Docker 引擎→db→迁移（首次或有更新）→后端→Web／Android。三端工程已经建立，当前业务范围及验证结果见[项目启动](项目启动.md)，后续产品模块状态见[功能对应的模块](功能对应的模块.md)。
