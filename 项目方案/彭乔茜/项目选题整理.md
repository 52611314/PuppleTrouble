# 项目选题整理

## 一、AI赋能学习生产力

### 2. 把日常声音做成乐器

- **目标场景：** 面向音乐初学者、艺术教育课堂和声音创作者，让杯子敲击、雨声、键盘声等随手可录的声音成为创作素材。
- **功能点：** 手机录音后，AI辅助完成有效片段切分、降噪和音色分类，将声音映射为可弹奏的键盘或鼓垫，并支持节奏编排与作品导出。
- **创新点 / 差异点：** 重点打通“发现身边声音—制作自己的乐器—演奏作品”的过程，保留声音来源，让采样与编曲成为直观的创作学习活动。

### 5. 自动整理和记忆创作者世界观与设定的 Agent

- **目标场景：** 面向小说、漫画和剧本创作者，解决长期创作中设定散落、人物关系难查和前后情节冲突的问题。
- **功能点：** 从章节、笔记和口述中提取人物、地点、规则与事件，维护设定库、关系图和时间线，并在新增内容时提示潜在矛盾及原文出处。
- **创新点 / 差异点：** 重点管理设定的版本、作者确认状态和“角色当时知道什么”，让每条提醒都有依据，设定取舍由创作者决定。

### 7. 可以重来一次的防骗剧情（推荐）

- **目标场景：** 面向想提高防骗意识的人，以及社区、学校的防骗教育活动，让参与者在模拟经历中练习识别风险。
- **功能点：** 将公开案例改编成可分支的互动剧情，结束后回到关键选择，展示当时已经出现的证据，并允许重新选择、比较后续结果。
- **创新点 / 差异点：** 以“当时掌握了哪些信息”为复盘依据，结合选择解释忽略的线索和受到的诱导，把防骗知识转化为过程中的判断练习。

## 二、AI融入日常

### 1. 会变形的网页（推荐）

- **目标场景：** 面向使用手机浏览复杂网页的人，根据“只看办理步骤”“专心阅读”“快速比较”等即时目标，减少查找信息和操作的负担。
- **功能点：** 通过自然语言表达需求，由AI识别页面内容与控件，重组信息层级、突出关键操作、调整字号和布局，并支持切换回原页面。
- **创新点 / 差异点：** 将网页适配细化到具体任务，使同一页面能随用户意图改变信息组织方式，同时保留内容来源与关键操作入口。

### 3. 收纳管理所有通知（推荐）

- **目标场景：** 面向被聊天、邮件、物流和日程等通知打断的人，集中整理用户授权且系统允许读取的通知来源。
- **功能点：** 利用AI按事件聚合通知、合并重复内容，提取待办与截止时间，形成即时提醒或定时摘要，并支持跳转原应用处理。
- **创新点 / 差异点：** 围绕“同一件事”持续更新状态，例如把发货、派送和取件通知整理成一条进展，帮助用户看清现在需要做什么。

### 4. 帮助老年人使用手机的远程无障碍助手（推荐）

- **目标场景：** 面向在挂号、出行和生活缴费等手机操作中遇到困难的老年人，以及无法当面协助的家属。
- **功能点：** 在老人主动授权的协助会话中，AI理解当前界面并给出大字、语音和位置提示，家属可远程指引，常用流程可保存为分步教程。
- **创新点 / 差异点：** 将家属的口头说明转成贴合当前界面的可执行指引，并通过重复引导帮助老人逐渐独立操作，付款等关键步骤由本人确认。

### 6. 给家乡话做一本会听的新词典（推荐）

- **目标场景：** 面向普通语音输入经常识别不了的方言使用者，以及希望共同记录家乡话的家庭。
- **功能点：** 将口述、原音和家人共同校订的文字逐条对应，积累可用于后续识别与检索的本地词汇，并为同一个词保留不同地区的读音、写法和例句。
- **创新点 / 差异点：** 以家庭共同校订和词条持续积累为核心，保留方言内部的地域差异，让原声记录与日常表达互相补充。

## 三、AI＋影像

### 8. 口述史记录与长辈回忆整理（推荐）

- **目标场景：** 面向希望保存长辈经历的家庭，将零散讲述整理为可以回看、检索和继续补充的家庭记忆，此处按“访谈影像整理”的产品形态归类。
- **功能点：** 支持手机录音、录像与老照片导入，由AI辅助转写、生成追问建议、梳理人物和时间线，并整理成带字幕、可编辑的故事章节或回忆短片。
- **创新点 / 差异点：** 每段整理内容都能回溯原声或原片，支持家人共同补充人物与年代，对记忆分歧和不确定细节保留标注，兼顾叙事表达与记录依据。
