# PuppleTrouble 接口文档

版本 v0.1，拟定契约，尚未实现。基路径 `/api/v1`，HTTPS JSON API；本机调试允许 HTTP。A 牵头架构与接口契约设计，B 共同确认并维护业务实现、契约发布和数据一致性；C/D 确认受影响的算法／移动需求，A 同步 Web 模型。字段或行为变更同步本文件及 [HANDOFF](HANDOFF.md)。后端实现后生成 `/openapi.json`，与本文件保持一致。

## 通用约定

- 字段 snake_case；标识为 UUID 字符串，本文样例的标识为示意。时间为 UTC ISO 8601，界面转北京时间。
- HEX 为大写 `#RRGGBB`、sRGB；透明度独立为 0～1。图像点坐标归一化到 0～1；模板元素用画布逻辑像素，不混用。
- 除 health、register、login 外需 `Authorization: Bearer <access_token>`。私有资源校验所有权，无权资源按 404 返回，不能只凭 UUID 授权。
- 列表采用 cursor 分页，limit 默认 20、最大 100；响应 data 含 items 和 next_cursor。色相默认排序同值按固定 id 破同序，中性色独立分组。
- 成功响应为 `{ "data": ..., "request_id": "..." }`；删除 204 无正文。错误为 `{ "error": { "code": "...", "message": "...", "details": {} }, "request_id": "..." }`。
- HTTP：400 参数语义错误，401 未登录或令牌过期，404 不存在，409 版本或幂等冲突，413 上传过大，415 类型不支持，422 字段校验，429 限流，502/503 外部能力不可用。
- POST 创建任务、创建候选和提交版本支持必填 `Idempotency-Key`（UUID）。服务器按用户＋方法＋路径＋key 保留 24 小时；相同请求返回原结果，不同正文返回 409。未确定结果时用同一个 key 重试，不能重复扣费或生成版本。

## 账户

| 方法与路径 | 输入 | 输出 |
|---|---|---|
| GET /health | 无 | 服务存活；不返回密钥或内部配置 |
| POST /auth/register | email、password（12～128 字符） | user_id；邮箱重复返回 409 |
| POST /auth/login | email、password | access_token、token_type=bearer、expires_in=3600 |
| GET /me | 令牌 | user_id、email |

登录与注册限流；首版无刷新令牌，过期后重新登录。注销清除客户端令牌和账户相关缓存。生产部署注册开放方式另行明确，不能公开使用通用演示账户。

## 颜色、作品与模板

| 方法与路径 | 参数或输入 | 返回要点 |
|---|---|---|
| GET /colors | family、style、scene、sort=hue/lightness/popular、cursor、limit | color_id、hex、display_name、family、tags；popular 无数据时返回确定的编辑推荐序并说明 sort_used |
| GET /colors/{id} | 无 | 色值、相近色、已整理说明及实例关联 |
| GET /artworks | color_id、style、scene、cursor、limit | 图像链接、名称、作者、授权状态及代表色 |
| GET /artworks/{id} | 无 | source_url、creator、date_text、license、图像宽高和 image_version、palette |
| POST /artworks/{id}/color-regions | target_hex、delta_e（默认 10，范围 1～40） | analysis_id、image_version、mask_asset_id、coverage、sample_hex、阈值与基于区域的解释 |
| GET /templates | scene、cursor、limit | template_id、name、thumbnail、canvas_schema_version |
| GET /templates/{id} | 无 | canvas、elements、默认 palette_roles；用于本地可编辑预览 |

颜色区域初版同步返回，使用预计算与缓存；接口受图片尺寸限制。coverage 是当前图像中颜色匹配像素的近似比例，不是语义物体面积。蒙版是与规范化图像同宽高的透明 PNG，返回版本避免错位。作品事实与 AI 分析分别提供 source_type、source_id，不混写为作者意图。

## 上传和图像分析

| 方法与路径 | 输入 | 输出 |
|---|---|---|
| POST /assets | multipart file、purpose=reference/page | asset_id、width、height、media_type、image_version；201 |
| GET /assets/{id}/content | 令牌 | 图片字节；应用经认证下载，链接本身不代表授权 |
| DELETE /assets/{id} | 令牌 | 204；被项目引用返回 409，先删除引用 |
| POST /analyses | asset_id、mode=palette、max_colors=3～12 | 202 job_id、status=queued |

单图默认上限 10 MB、解码 2500 万像素，仅 JPEG/PNG/WebP 静态图片。验证实际格式，去除 EXIF 位置等元数据并保留处理说明，ICC 转换后进入 sRGB；不接受服务端任意 URL 下载。

分析任务结果包含 colors[{hex,coverage}]、mask_asset_ids、normalization、warnings、analysis_source。公开馆藏分析与私人上传访问权限分开。缓存键包含图像版本、阈值、色彩算法版本。

## 项目和页面模型

| 方法与路径 | 输入 | 输出 |
|---|---|---|
| GET /projects | cursor、limit | 当前用户项目摘要 |
| POST /projects | title、template_id、reference_asset_ids | 201 project_id、version=1、palette_id、完整页面 |
| GET /projects/{id} | 无 | 当前权威版本与页面 |
| PATCH /projects/{id} | base_version、title | 原子更新元信息并增加版本；过期返回 409 |
| DELETE /projects/{id} | 无 | 204；取消其任务并删除私有引用，按保留策略清理未引用素材 |
| GET /projects/{id}/versions | cursor、limit | 历史版本元信息 |
| GET /projects/{id}/versions/{version} | 无 | 只读页面快照 |
| POST /projects/{id}/versions | base_version、document、proposal_id（可空） | 校验并创建新版本；返回 version、palette_id；201 |
| POST /projects/{id}/restore | base_version、restore_version | 将历史快照复制为新的当前版本；不删除后续历史 |

document 是权威结构化页面，含 canvas_schema_version=1、canvas{width,height}、palette_roles、locked_roles、elements。角色固定为 background、text、primary、accent、supporting；每个角色有 hex 与 locked。locked_roles 与各角色 locked 必须一致。

elements 支持 text/image/shape/chart，均包含 id、type、x、y、width、height、z_index、opacity。文字保存 text、font_size、font_weight；图片保存 asset_id；形状保存 shape_type。可配色属性通过 fill_role、stroke_role、text_role 绑定角色，允许经确认的显式 hex；锁定元素用 locked=true。首版禁用任意脚本、HTML 和远程字体 URL。图表仅接收类型和原始数值数组，颜色通过角色绑定。

版本写入使用数据库事务和 compare-and-swap 校验 base_version；409 返回 current_version，客户端重载或保留草稿后再处理。前端局部撤销不写历史；确认保存才生成服务器新版本。恢复旧版本是新写入操作，不能静默回滚服务器版本号。

## 配色推荐和局部调整

| 方法与路径 | 输入 | 输出 |
|---|---|---|
| POST /projects/{id}/palette-proposals | base_version、reference_artwork_id（可空）、brief、locked_roles、locked_element_ids、candidate_count=1～3 | 202 job_id；产生只读候选，不修改项目 |
| POST /projects/{id}/adjustments | base_version、instruction、locked_roles、locked_element_ids、proposal_id（可空） | 202 job_id；基于指定版本或该版本的候选产生新候选 |
| GET /jobs/{id} | 令牌 | queued/running/succeeded/failed/cancelled、result 或 error |
| DELETE /jobs/{id} | 令牌 | 202 取消请求；已终态返回终态，尽力停止外部调用 |

调整请求示例：

```json
{
  "base_version": 3,
  "instruction": "保留主蓝色，让背景温暖一点，照片不要动",
  "locked_roles": ["primary"],
  "locked_element_ids": ["photo_1"],
  "proposal_id": null
}
```

成功任务的 result 示例（放在 data.result 内）：

```json
{
  "base_version": 3,
  "analysis_source": "model",
  "proposals": [{
    "proposal_id": "proposal-example",
    "palette_roles": {
      "background": {"hex": "#F5EFE6", "locked": false},
      "text": {"hex": "#242424", "locked": false},
      "primary": {"hex": "#3155A4", "locked": true},
      "accent": {"hex": "#B5532B", "locked": false},
      "supporting": {"hex": "#D8D2C8", "locked": false}
    },
    "changes": [{"role": "background", "from": "#EEF2F8", "to": "#F5EFE6"}],
    "reason": "仅调整背景与辅助色，保留主蓝色及照片元素。",
    "warnings": [],
    "evidence_refs": []
  }]
}
```

初版候选仅允许修改角色色值，不改变文本、图层位置、原始图片和图表数据。未来结构修改增加新的 schema 版本。锁定列表与已保存项目锁定项取并集；解锁需用户先明确保存新的锁定状态，不能通过省略请求字段绕过锁定。

changes、最终 palette_roles 与锁定项由服务器再次校验；reason 不作为校验依据。来源枚举 model/rule/mock，mock 必须在 UI 显示“模拟”。候选相对 base_version 有效，确认时再次检查版本，不能把陈旧候选覆盖新编辑。

任务初始总超时 90 秒，每用户最多 2 个活动任务，返回 retry_after_ms；客户端前台初始 1 秒轮询、逐步退避到 5 秒。页面离开停止轮询，返回后查询任务；服务端任务不会因 UI 退出自动保存。外部超时返回 JOB_TIMEOUT，任务结果保留 24 小时；项目版本按项目保存。规则降级要有明确来源和提示，不能伪装为模型结果。

## 收藏、偏好与导出

| 方法与路径 | 输入 | 输出 |
|---|---|---|
| GET /favorites | kind=color/artwork/palette、cursor、limit | 当前用户收藏 |
| PUT /favorites/{kind}/{id} | kind=color/artwork/palette | 幂等收藏，200；palette 的 id 为已保存版本所绑定的方案 id |
| DELETE /favorites/{kind}/{id} | 无 | 幂等删除，204 |
| GET /preferences | scope=personal/project、project_id（project 时必填） | 有证据和范围的偏好 |
| POST /preferences | scope、project_id、statement、evidence_version、confirmed=true | 201 preference_id；个人偏好须用户显式确认 |
| DELETE /preferences/{id} | 无 | 204，清除对应偏好和相关缓存 |
| POST /projects/{id}/exports | version、format=json/png | 202 job_id；result 含 export_id |
| GET /exports/{id}/content | 令牌 | 带 Content-Disposition 的下载字节 |

PNG 首版由 Web 从固定版本场景通过 Konva 导出，Android 对支持的少量模板以原生渲染后使用系统分享；服务端 format=png 可返回 422 EXPORT_FORMAT_UNAVAILABLE，并由相应客户端转入本地导出，不承诺双端渲染已实现。JSON 导出服务端提供且只含用户项目配色与页面参数，不夹带密钥和私人来源数据。可选 CSS 导出后续扩展。

## 关键错误代码和验收

VERSION_CONFLICT、IDEMPOTENCY_CONFLICT、COLOR_LOCK_VIOLATION、ASSET_IN_USE、MODEL_OUTPUT_INVALID、MODEL_UNAVAILABLE、JOB_TIMEOUT、EXPORT_FORMAT_UNAVAILABLE。

必须验证：颜色被锁定时不能修改；候选生成不产生新版本；重复请求只产生一次资源；过期 base_version 返回冲突；用户 B 无法读取 A 的项目、任务、素材和导出；超时和取消后旧项目保持原样。开发中新增响应字段可向后兼容，移除字段或改变角色语义要升级契约。

## Web 与移动端共同约定

Web 负责完整画布编辑，Android 负责颜色探索、拍照输入、原生模板预览和轻量调色。二者请求相同 `/api/v1`，共用颜色角色与版本。两端同时保存触发 base_version 校验，客户端保留草稿并显示冲突，不能以最后写入静默覆盖。

Web 使用 Authorization 请求头，访问令牌仅保存在内存；页面刷新后重新登录。后端允许配置的开发源跨域，放行 Authorization、Content-Type、Idempotency-Key 头和必要方法；生产优先同域代理。不能将浏览器 CORS 当作所有权校验。

候选不带可执行 HTML，图像通过认证接口获取。A/D 共享规范色值、蒙版尺寸与固定模板样例；布局显示允许经过检查的字体差异，推荐色值与锁定行为必须一致。
